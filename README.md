# tp3_so

Para compilar, basta utilizar o comando "make". A execução então é feita com o comando "make run". 

Os comandos suportados no shell são e o formato esperado por cada:

init - inicializar o sistema de dados;

load - carregar o sistema no disco;

mkdir (mkdir nome_do_diretório ou mkdir /caminho/nome_do_diretório) - cria um diretório;

create (create nome_do_arquivo ou mkdir /caminho/nome_do_arquivo) - cria um arquivo;

unlink (unlink nome_arquivo_ou_diretório ou unlink /caminho/nome_arquivo_ou_diretório) - exclui arquivo ou diretório;

write (write nome string ou write /caminho/nome string) - escreve dados em um arquivo;

append (append nome string ou append /caminho/nome string) - anexa dados em um arquivo;

read (read nome ou read /caminho/nome) - lê o conteúdo de um arquivo;
